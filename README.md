# My-project
The project consists of creating an interactive geography quiz in Python. The user will answer a series of questions about countries and their capitals. At the beginning of the program, the user will choose a difficulty level: easy, medium, or hard. Depending on the selected level, the program will display different questions.

For each question, the user will type an answer. The program will check whether the answer is correct, give immediate feedback, and update the score. If the answer is wrong, the correct answer will be displayed. At the end of the quiz, the program will show the final score and the percentage of correct answers.

The objective of the project is to create a simple educational game that helps users improve their geography knowledge while practicing fundamental Python concepts such as variables, conditional statements, loops, lists, user input, and score calculation.
